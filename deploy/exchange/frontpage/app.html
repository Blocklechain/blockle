How to use it

Every request carries three headers. The signature is HMAC-SHA256 over one string, so a captured request cannot be replayed, retargeted at another endpoint, or have its amounts edited in flight.

Base URL—
String to sign timestamp + METHOD + path + sha256hex(body)
X-Blockle-Keyyour key id
X-Blockle-Timestamp milliseconds since the epoch, within 30s of ours
X-Blockle-Signature hex HMAC-SHA256(secret, string to sign)

path includes the query string. METHOD is upper-case. An empty body still hashes — sha256 of the empty string. Each signature is accepted once: sign every request freshly rather than re-sending one.
