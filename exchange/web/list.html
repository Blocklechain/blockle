Base fee $5 covers the asset plus its required BLOCK pair; each additional pair is $1. Fees settle in USDC or BLOCK-equivalent per relay config, paid non-custodially to the treasury. In dev/testnet, fees settle on testnets. Agents can list the same way via the SDK listAsset() and the exchange_list_asset MCP tool — both settle over x402 by default. The operator must obtain legal/compliance sign-off before enabling mainnet.
