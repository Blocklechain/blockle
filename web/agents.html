Blockle for Agents

Run a wallet, launch a BLOCK-20 token, seed the native AMM, trade, and sell — programmatically, with signing byte-identical to consensus (ML-DSA-44).

Install

TypeScript SDK

# from the monorepo (the SDK links the wasm signer locally)
cd blockle-wasm && wasm-pack build --target nodejs --out-dir pkg-node
cd ../sdk && npm install && npm run build

MCP server (any MCP-capable agent)

cd mcp && npm install && npm run build
# stdio (for a desktop/agent client):
node dist/src/index.js
# or streamable-HTTP:
node dist/src/index.js --http

Point your MCP client at the blockle-mcp binary (stdio) or its HTTP endpoint. Tools wrap the SDK one-to-one; see mcp/README.md and sdk/AGENTS.md.

The full loop

Every step is one SDK call / one MCP tool. Amounts are always in base units (1 BLOCK = 100,000,000 base units).

  • Buy BLOCK — primary sale over the sqrt buy-curve (x402 payment rail, services/x402-buy). 5% buy fee.
  • Launch a token — deploy a BLOCK-20 token (build_block20_token); selectors 0 init … 6 symbol.
  • Create a pool — one constant-product AMM pool per token (build_pool_create + build_pool_add). LP locked 1008 blocks.
  • Trade — build_pool_swap_buy / build_pool_swap_sell; 0.30% swap fee. Quote/slippage math in web/dex.js.
  • Sell BLOCK → USDC — redemption through services/settlement (reorg-safe depth, daily cap, idempotent ledger).
  • Cross-chain — non-custodial atomic swaps (HTLC) and permissionless listings at exchange.blockle.org.

Base-unit conventions

  • 1 BLOCK = 1e8 base units. Keep everything in base units; convert only at display edges.
  • gas_price = 10 base units / gas. fee = gas_limit * 10.
  • Inputs must cover block_amt/block_in plus the fee.
  • Per-action gas: deploy 300000, init 120000, pool create 250000, swap/call 200000.
