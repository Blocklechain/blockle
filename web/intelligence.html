Verifiable intelligence, paid for in BLOCK.

Subnets are task markets. Miners produce work; validators score it against beacon-seeded checks; honest work earns a share of the BLOCK emission. One command to start — blockle intel register-neuron — and earnings land in your wallet.

Start earning — one command

# register as a miner on subnet 0 (locks a small BLOCK bond)
blockle intel register-neuron --subnet 0 --role miner --bond 1

# check what you've earned, then claim it to your wallet
blockle intel status
blockle intel claim

Validators additionally run commit-weights → reveal-weights → validate each epoch. See the protocol spec.

Blockle Intelligence is on testnet; mainnet activation is audit-gated. Emission redirects a small share of the block subsidy to useful work — the BLOCK supply schedule is unchanged. Not investment advice.
