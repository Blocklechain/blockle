Blockle Notary

Tamper-evident, independently-verifiable timestamps for any document — anchored on the Blockle blockchain. You send only a SHA-256 hash; the document itself never leaves your systems.

Why

  • Prove a file existed, unaltered, at a point in time — contracts, records, audit logs, journalism, IP.
  • Verifiable by anyone, forever, without trusting Blockle — the proof is on-chain.
  • Privacy by construction: we only ever see a hash.

Get a key

curl -s https://protect.blockle.org/api/notary/signup \
  -H "content-type: application/json" \
  -d '{"email":"you@company.com","org":"Acme Inc"}'

Your API key is emailed to you (and returned once). Free tier: 50 anchors.

Anchor a hash

curl -s https://protect.blockle.org/api/notary/anchor \
  -H "Authorization: Bearer blk_live_..." \
  -H "content-type: application/json" \
  -d '{"hash":"<sha256-hex-of-your-document>"}'
# → { "hash": "...", "txid": "...", "verifyUrl": "..." }

Verify (public, no key)

curl -s https://protect.blockle.org/api/notary/verify/<sha256-hex>
# → { "anchored": true, "height": 50469, "chain": "blockle" }
